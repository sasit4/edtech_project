# EdTech Learning Platform

## Overview

EdTech Learning Platform is a web-based Learning Management System (LMS) developed using Django. The platform enables users to learn online through courses, quizzes, leaderboards, and certificate generation.

## Objective

The objective of this project is to provide an interactive online learning environment where users can improve their skills, assess their knowledge through quizzes, and earn certificates upon successful completion.

## User Roles

### Student

* Register and login to the platform
* Access available courses
* Attend quizzes
* View quiz results
* Download certificates
* Check leaderboard rankings

### Teacher

* Manage learning content
* Create and update courses
* Manage quizzes and questions

### Admin

* Manage users and teachers
* Manage courses and categories
* Manage quizzes and certificates
* Monitor platform activities

## Modules

### User Management

### Course Management
